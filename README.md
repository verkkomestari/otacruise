Website for Otacruise, a student cruise for Aalto University students.

Basic commands

- Install dependencies: `npm install`
- Start dev server: `npm run dev`
- Build production bundle: `npm run build` (outputs `dist`)
- Preview production build: `npm run preview`

Notes

- Use the Node LTS (see `.nvmrc`) for development and CI.
- Netlify (if used) should publish the `dist` directory.
